Три способа обучить команду

{% icon "EDU" %}

Онлайн-курсы — самостоятельно

Курсы по ролям на портале «1С:Отель»: первоначальная настройка базы, фронт-офис, бронирование, управление тарифами. Проходятся в своём темпе, с любого устройства — новый сотрудник осваивает систему сам, не отвлекая старшего смены.

Курсы на 1c-hotel.pro
{% icon "MON" %}

Индивидуально — онлайн, под ваш отель

Учим вашу команду на вашей конфигурации, тематическими блоками с вопросами и ответами после каждого: служба приёма — заезд, выезд, шахматка, касса; бронирование и продажи — тарифы, квоты, групповые брони; отчётность и обмен с бухгалтерией. Состав групп и темы подстраиваем под объект.

{% icon "OPS" %}

На проекте — перед запуском

Обучение входит во внедрение: команда работает на тестовом контуре до переключения, с разбором нештатных ситуаций. В первые дни после старта остаёмся на связи с каждой сменой, чтобы вопрос у стойки решался за минуту, а не заявкой в поддержку.

Кого учим

Разным ролям — разное обучение

Администратору стойки не нужен курс по управленческим отчётам, а руководителю — по закрытию смены. Каждый учится своим сценариям.

  1. Администратор стойкиЗаселение, выселение, касса, нештатные ситуации на реальных сценариях.
  2. Служба бронированияТарифы, квоты, групповые брони, работа с каналами продаж.
  3. БухгалтерЗакрытие смены, сверка кассовых операций, обмен с 1С:Бухгалтерией.
  4. РуководительОтчёты по загрузке и выручке вместо сводки «на словах».
  5. Новый сотрудникОнлайн-курс по своей роли и короткий разбор особенностей объекта.
