Набор написан под текущий сайт: Django 6.1 в ветке `django`. Всё, что было под Flask, переписано 06.09.2026.

## Скиллы — процедуры без выбора

| Задача | Скилл |
|---|---|
| Запустить сайт и посмотреть | `preview-site` |
| Проверить ссылки, метатеги, JSON-LD, sitemap | `check-site` |
| Добавить услугу, решение или статью | `add-page` |
| Включить админку | `enable-admin` |
| Собрать архив для хостинга | `package-for-deploy` |
| Пересобрать favicon и картинку для соцсетей | `rebuild-assets` |

## Агенты — работа с суждением

| Задача | Агент |
|---|---|
| Написать текст страницы или статьи | `content-writer` |
| Проверить вёрстку на разных ширинах | `layout-qa` |
| Сверить оформление с брендбуком | `brandbook-checker` |
| Проверить SEO по смыслу, а не только формально | `seo-auditor` |
| Проверить приём заявок: безопасность, 152-ФЗ, потери | `lead-form-reviewer` |
| Понять, готовы ли к публикации | `deploy-checklist` |

## Как выбирать

Порядок действий известен заранее и выбирать не из чего — скилл. Нужна оценка, разбор или роль со своим взглядом — агент. Проверка кода на баги — встроенная команда `/code-review`, отдельного агента для неё заводить не нужно.

Типичные связки:

- Поправили CSS: `preview-site`, затем агенты `layout-qa` и `brandbook-checker`.
- Добавили страницу: `add-page`, затем `check-site`, затем `seo-auditor`.
- Собираетесь публиковать: `check-site`, агент `deploy-checklist`, затем `package-for-deploy`.

## Если готового нет

Сначала посмотреть, не покрывает ли задачу существующий скилл целиком. Если нет — сказать об этом прямо и предложить завести новый, а не выполнять вслепую. Готовые публичные скиллы для Claude Code ищутся навыком `find-skill`.

## Что устарело

В репозитории больше нет `app.py`, реестра `PAGES`, каталога `src/` и сборки `dist/`. Любая инструкция, ссылающаяся на них, относится к прежней версии сайта: её исходники лежат в `reference-old-site/` только как источник текстов.
